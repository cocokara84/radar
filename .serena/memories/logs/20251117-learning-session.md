## Rationale（理由・背景）

### 問題の発端
ステアリングベクトルの位相普遍性実験で内積がゼロになる問題が発生：

```python
# ユーザーの実装
x_complex = sin(ωt + φ) + j·cos(ωt + φ)
steering_vector = e^(-jωt)
inner_product = Σ(x_complex * steering_vector)  # 共役なし
→ 結果: ほぼゼロ
```

### 2つの問題を発見

**問題1**: 複素数の定義が誤り
- `sin(θ) + j·cos(θ)` ≠ `e^(jθ)`
- 正しくは `cos(θ) + j·sin(θ) = e^(jθ)`
- 実部と虚部が逆

**問題2**: 共役転置を使っていない
- 正しくは `np.vdot(a, b)` または `np.sum(np.conj(a) * b)`
- 共役により「位相差」を計算できる

### 根本原因の認識
問題解決の過程で、より深い課題が判明：

1. **暗黙知の壁**: レーダー特有の「当たり前」が分からない
2. **質問の困難**: 何を実験すべきか自力で決められない
3. **既存ドキュメントの限界**: 専門的すぎて初学者に不適

### 解決策の必要性
- 深層学習専門家がレーダーを学ぶための体系的なガイドが必要
- 実験駆動で段階的に理解を深めるシステムが必要
- セッション間の連続性を保つ仕組みが必要

## 学んだこと

### 技術的な学び

1. **複素指数関数の正しい形**
   - `e^(jθ) = cos(θ) + j·sin(θ)`
   - 実部が cos、虚部が sin（この順序が重要）

2. **共役転置の必要性**
   - 複素内積: `<a, b> = Σ conj(a_i) × b_i`
   - 共役により位相差を計算
   - 物理的には「どれだけ位相がずれているか」を測定

3. **位相普遍性の意味**
   - 全体位相回転 `e^(jφ) · a(θ)` は物理的に無意味
   - 重要なのは相対位相のみ
   - ステアリングベクトルマッチングでは絶対位相に依存しない

4. **データ長の影響**
   - アンテナ素子数が変わっても、正規化すれば問題ない
   - 内積の絶対値は素子数Mに比例
   - 正規化: `a / sqrt(M)` で素子数に依存しない

### レーダー固有の暗黙知（新規発見）

1. 複素数の内積には必ず共役を使う
2. ステアリングベクトルは正規化する
3. 位相は「相対的」であり絶対値は無意味
4. 空間領域と時間領域の類似性（変数名tでもアンテナインデックスの場合がある）

### 学習プロセスの学び

1. **意図確認の重要性**: 実装を見たら、まず意図を確認
2. **暗黙知の発見**: ユーザーの疑問が暗黙知発見のトリガー
3. **文書化の威力**: 対話と文書化のサイクルが学習を加速
