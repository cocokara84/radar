# レーダー信号処理 学習ロードマップ

このドキュメントは、深層学習専門家がレーダー信号処理を段階的に学ぶための全体像を示します。

---

## 学習の全体構造

```
Phase 1: 基礎（複素数とステアリングベクトル）
  ↓
Phase 2: ビームフォーミング（最も基本的な方向推定）
  ↓
Phase 3: 高度な手法（Capon, MUSIC, ESPRIT）
  ↓
Phase 4: 深層学習との統合
  ↓
Phase 5: End-to-Endシステムの構築
```

## 挫折しないためのヒント

### 1. 小さく始める
- 1つの質問に集中
- 完璧を求めず、まず動かす
- 理解が浅くても次に進む（後で戻ればOK）

### 2. 実験ファースト
- 数式を読んで悩むより、コードを書く
- 結果を見てから理論を理解
- プロットで視覚化

### 3. 深層学習との対比
- 常に「深層学習では？」と比較
- 既存知識を活用
- 新しい概念は既知の概念に紐付ける

### 4. 定期的な振り返り
- 週1回、learning_status.mdを更新
- 学んだことをexperiment_log.mdに記録
- AIに「今週何を学びましたか？」と聞く

### 5. 無理しない
- 疲れたら休む
- 分からないことは素直に聞く
- ペースを調整する
