## 1. IQ検波の原理

### 1.1 基本概念
レーダーが受信する信号は、搬送波周波数 $f_c$ の高周波信号です。この信号から有用な情報（振幅、位相）を取り出すために**IQ検波**を行います。

**受信信号**:
```
r(t) = A(t) · cos(2πf_c·t + φ(t))
```
- `A(t)`: 時間変化する振幅（物体からの反射強度）
- `φ(t)`: 時間変化する位相（物体の距離や速度に関連）

### 1.2 検波プロセス

2つの基準信号を用意します:
- **I成分（In-phase）**: `cos(2πf_c·t)` ← 搬送波と同位相
- **Q成分（Quadrature）**: `sin(2πf_c·t)` ← 搬送波と90度位相差

受信信号にそれぞれを掛け算（ミキシング）すると:

**I成分の検波**:
```
I(t) = r(t) × cos(2πf_c·t)
     = A(t)·cos(φ(t))  (高周波成分を除去後)
```

**Q成分の検波**:
```
Q(t) = r(t) × sin(2πf_c·t)
     = A(t)·sin(φ(t))  (高周波成分を除去後)
```

### 1.3 複素数表現

IとQを複素数としてまとめると:
```
s(t) = I(t) + j·Q(t) = A(t)·e^(jφ(t))
```

**物理的意味**:
- 複素平面上で、振幅 `A(t)` の円を描きながら、位相 `φ(t)` の角度で回転
- 時間軸方向から見ると「バレルロール」のような螺旋軌道
- 位相の変化速度（角速度）が物体の移動速度（ドップラー効果）を表す

## 2. アレイアンテナの基礎

### 2.1 複数アンテナによる受信

等間隔 `d` で並んだ `N` 本のアンテナがあるとします。

```
アンテナ配置:  [0] ---- [1] ---- [2] ---- ... ---- [N-1]
               ← d → ← d →
```

物体が角度 `θ` の方向から電波を送ってくると、各アンテナには**到達時間差**が生じます。

### 2.2 位相差の発生メカニズム

角度 `θ` から到来する平面波は、隣接アンテナ間で以下の経路差が生じます:

```
経路差 = d · sin(θ)
```

電波の波長を `λ` とすると、**位相差**は:

```
Δφ = (2π/λ) · d · sin(θ)
```

**重要な観察**:
- アンテナ `n` が受信する信号の位相 = `n × Δφ`
- 各アンテナの受信信号をアンテナインデックスに沿ってプロットすると**正弦波**になる
- この正弦波の「空間周波数」が `Δφ` であり、物体の方向 `θ` に対応

### 2.3 数学的表現

アンテナ `n` の受信信号（IQ検波後）:
```
s_n = A · e^(j·n·Δφ) = A · e^(j·n·(2π/λ)·d·sin(θ))
```

すべてのアンテナの受信をベクトルとしてまとめると:
```
s = [s_0, s_1, s_2, ..., s_{N-1}]^T
```

## 3. ステアリングベクトルの物理的意味

### 3.1 ステアリングベクトルとは何か

**ステアリングベクトル** `a(θ)` は、「角度 `θ` から信号が到来したときに、各アンテナが受信する信号の位相パターン」を表す理論的なベクトルです。

```
a(θ) = [1, e^(jΔφ), e^(j2Δφ), ..., e^(j(N-1)Δφ)]^T
```

ここで `Δφ = (2π/λ) · d · sin(θ)`

### 3.2 なぜ「異なる周波数」と表現されるのか

- 時間領域での「周波数」は時間あたりの位相変化
- 空間領域での「空間周波数」はアンテナインデックスあたりの位相変化
- 角度 `θ` が異なると `Δφ` が異なる → **空間周波数が異なる**

**比喩的理解**:
- 時間信号: `e^(j2πft)` → `f` が周波数
- 空間信号: `e^(jnΔφ)` → `Δφ` が空間周波数（角度 `θ` に対応）

### 3.3 内積による方向推定の原理

実際の受信信号ベクトル `s` と、仮定した角度 `θ'` のステアリングベクトル `a(θ')` の内積を取ります:

```
P(θ') = |a(θ')^H · s|^2
```
- `^H`: エルミート転置（複素共役転置）
- `| |^2`: 絶対値の2乗（パワー）

**物理的意味**:
1. 実際の信号 `s` が角度 `θ` から到来している
2. `θ' = θ` のとき、`a(θ') = a(θ)` なので位相パターンが完全に一致
3. **内積が最大**になる → ベクトルが同じ方向を向いている
4. `θ' ≠ θ` のとき、位相パターンがずれて内積が小さくなる

**フーリエ変換との類似**:
- 時間信号のFFT: 異なる周波数の正弦波との内積を計算
- 空間信号の方向推定: 異なる角度のステアリングベクトルとの内積を計算

この「全ての角度について内積を計算して最大値を探す」操作が**ビームフォーミング**の基本です。

### 3.4 具体例

**設定**:
- アンテナ数 `N = 4`
- アンテナ間隔 `d = λ/2`（半波長）
- 物体の角度 `θ = 30°`

**計算**:
```
Δφ = (2π/λ) · (λ/2) · sin(30°) = π/2 = 90°
```

**ステアリングベクトル**:
```
a(30°) = [e^(j·0°), e^(j·90°), e^(j·180°), e^(j·270°)]^T
       = [1, j, -1, -j]^T
```

各アンテナの位相が90度ずつずれています。実際の受信信号が `s = A·[1, j, -1, -j]^T` ならば、`a(30°)` との内積は最大になります。

## 4. 到来方向推定アルゴリズム

### 4.1 ビームフォーミング（Beamforming）

#### コンセプト
最もシンプルな方法。全ての角度について「その方向から信号が来たと仮定したときの受信パワー」を計算します。

#### 数式
```
P_BF(θ) = |a(θ)^H · s|^2 / N
```

#### 物理的意味
- アンテナアレイを特定の方向 `θ` に「向ける」ことに相当
- その方向からの信号を強調し、他の方向からの信号を抑圧
- **アンテナの指向性パターン**を電気的に制御

#### 限界
- **角度分解能が低い**: 2つの近い物体を区別できない
- レイリー限界: `Δθ ≈ λ/(N·d)` 程度の角度差が必要

---

### 4.2 Capon法（MVDR: Minimum Variance Distortionless Response）

#### コンセプト
ビームフォーミングの改良版。「目的の方向からの信号は歪ませず、他の方向からの干渉を最小化する」重み付けを最適化します。

#### アプローチ
1. 受信信号の共分散行列を計算: `R = E[s·s^H]`
2. 最適な重みベクトル `w` を求める最適化問題を解く:
   ```
   minimize: w^H·R·w
   subject to: w^H·a(θ) = 1
   ```

#### 解
```
w_Capon(θ) = R^(-1)·a(θ) / (a(θ)^H·R^(-1)·a(θ))
```

#### 空間スペクトル
```
P_Capon(θ) = 1 / (a(θ)^H·R^(-1)·a(θ))
```

#### 物理的意味
- 共分散行列 `R` が干渉やノイズの統計的性質を表す
- `R^(-1)` により、干渉が強い方向を自動的に抑圧
- ビームフォーミングより**高い角度分解能**を実現

#### 優位性
- 複数の信号源がある場合、互いの干渉を抑えつつ分離可能
- SNRが高い状況で性能向上が顕著

---

### 4.3 MUSIC (Multiple Signal Classification)

#### コンセプト
共分散行列の**固有値分解**を利用し、信号部分空間とノイズ部分空間を分離する超分解能手法。

#### 理論的背景

**信号モデル**:
```
s = Σ[k=1 to K] a(θ_k)·x_k + n
```
- `K`: 信号源の数
- `θ_k`: k番目の信号源の角度
- `x_k`: k番目の信号の複素振幅
- `n`: ノイズベクトル

**共分散行列の固有値分解**:
```
R = E[s·s^H] = U_S·Λ_S·U_S^H + U_N·Λ_N·U_N^H
```
- `U_S`: 信号部分空間（K個の大きい固有値に対応する固有ベクトル）
- `U_N`: ノイズ部分空間（N-K個の小さい固有値に対応する固有ベクトル）

**重要な性質**:
- 信号のステアリングベクトル `a(θ_k)` は**信号部分空間に属する**
- ノイズ部分空間と信号ステアリングベクトルは**直交する**:
  ```
  a(θ_k)^H · U_N = 0
  ```

#### MUSICスペクトル
```
P_MUSIC(θ) = 1 / (a(θ)^H·U_N·U_N^H·a(θ))
             = 1 / ||U_N^H·a(θ)||^2
```

#### 物理的意味
- ノイズ部分空間への射影の大きさを計算
- 真の信号角度 `θ_k` では射影がゼロ → **スペクトルに鋭いピーク**
- 理論的には無限の角度分解能（実際はノイズで制限される）

#### アルゴリズム手順
1. 共分散行列 `R` を推定（複数スナップショットの平均）
2. `R` を固有値分解
3. 信号源数 `K` を推定（大きい固有値の数）
4. ノイズ固有ベクトル `U_N` を抽出
5. 全角度について MUSICスペクトル `P_MUSIC(θ)` を計算
6. ピークを検出 → 物体の角度

#### 優位性
- **超分解能**: レイリー限界を超える角度分解能
- 複数の近接した信号源を分離可能

#### 制約
- 信号源数 `K < N`（アンテナ数未満）
- スナップショット数が十分必要（統計的推定のため）
- 計算コストが高い（固有値分解）

---

### 4.4 ESPRIT (Estimation of Signal Parameters via Rotational Invariance Techniques)

#### コンセプト
MUSICの改良版。アンテナアレイの**回転不変性**を利用して、角度スペクトルを計算せずに直接角度を推定します。

#### 前提条件
アンテナアレイが2つの重なったサブアレイに分割できること:

```
サブアレイ1: [0, 1, 2, ..., N-2]
サブアレイ2: [1, 2, 3, ..., N-1]
```

#### 理論
2つのサブアレイのステアリングベクトルには以下の関係があります:
```
a_2(θ) = Φ · a_1(θ)
```
ここで `Φ = diag[e^(jΔφ_1), ..., e^(jΔφ_K)]` は**回転行列**

#### アルゴリズム
1. 共分散行列の固有値分解で信号部分空間 `U_S` を取得
2. サブアレイに対応する `U_S1`, `U_S2` を抽出
3. 回転行列 `Φ` を推定:
   ```
   Φ = (U_S1^H·U_S1)^(-1)·U_S1^H·U_S2
   ```
4. `Φ` の固有値から位相差 `Δφ_k` を取得
5. 角度を逆算:
   ```
   θ_k = arcsin(λ·Δφ_k / (2π·d))
   ```

#### 優位性
- MUSICより計算効率が良い（全角度探索が不要）
- 角度推定精度が高い
- 自動的にペアリング（複数信号の対応付け）が可能

---

### 4.5 Root-MUSIC

#### コンセプト
MUSICの変形版。1次元アレイでは、MUSICスペクトルのピーク探索を**多項式の根を求める問題**に変換できます。

#### 理論
ステアリングベクトルを多項式として表現し、分子を最小化する根を求めます。

#### 優位性
- 計算効率が良い（FFT不要）
- 角度グリッドの離散化誤差がない

---

### 4.6 アルゴリズム比較表

| アルゴリズム | 角度分解能 | 計算コスト | SNR要求 | 複雑度 | 適用場面 |
|------------|----------|----------|---------|-------|---------|
| Beamforming | 低 | 低 | 低 | 低 | リアルタイム、低SNR |
| Capon | 中 | 中 | 中 | 中 | 干渉抑圧が必要 |
| MUSIC | 高 | 高 | 高 | 高 | 高精度が必要 |
| ESPRIT | 高 | 中 | 高 | 高 | 効率と精度の両立 |
| Root-MUSIC | 高 | 中 | 高 | 高 | 1次元アレイ |

## 5. Range-Doppler処理

### 5.1 FMCWレーダーの基本

**FMCW (Frequency Modulated Continuous Wave)** レーダーは、周波数が時間とともに変化する**チャープ信号**を送信します。

**チャープ信号**:
```
f(t) = f_0 + B·t/T_c
```
- `f_0`: 開始周波数
- `B`: 帯域幅（周波数変化幅）
- `T_c`: チャープ時間

### 5.2 距離（Range）の測定原理

#### 送信信号と受信信号の時間差
物体までの距離 `R` があると、往復時間は:
```
τ = 2R/c
```
(`c`: 光速)

受信信号は送信信号より時間 `τ` だけ遅れます。

#### ビート周波数
送信信号と受信信号をミキシングすると、**ビート周波数** `f_b` が発生:
```
f_b = B·τ/T_c = (2B/cT_c)·R
```

**重要**: ビート周波数 `f_b` が距離 `R` に**比例**します。

#### FFTによる距離推定
IQ検波後の信号をFFTすると、ビート周波数成分が現れます:
```
FFT{受信信号} → ピーク周波数 f_b → 距離 R = (cT_c/2B)·f_b
```

これが**チャープ内FFT**です。

### 5.3 速度（Doppler）の測定原理

#### ドップラー効果
物体が速度 `v` で移動していると、受信信号の周波数が**ドップラーシフト** `f_d` します:
```
f_d = (2v/λ)·f_c
```
- `λ`: 波長
- `f_c`: 搬送波周波数

#### 複数チャープでの観測
連続した `M` 個のチャープを送信すると、各チャープで同じ距離ビンに物体が観測されますが、**位相が回転**します:
```
第 m 番目のチャープでの位相 = 2π·f_d·m·T_c
```

#### チャープ間FFT
同一距離ビンについて、チャープインデックス `m` 方向にFFTを適用:
```
FFT{複数チャープの同一距離ビン} → ドップラー周波数 f_d → 速度 v
```

### 5.4 Range-Dopplerマップ

**2次元FFT処理**:
1. **チャープ内FFT**: 各チャープについて時間方向にFFT → 距離情報
2. **チャープ間FFT**: 各距離ビンについてチャープ方向にFFT → ドップラー情報

結果は2次元のスペクトル（Range-Dopplerマップ）:
```
          距離 →
速度  [   ...   ]
 ↓    [   ...   ]
      [ ピーク  ]
```

**物理的意味**:
- 横軸: 物体までの距離
- 縦軸: 物体の速度（近づく/遠ざかる）
- 各ピーク: 1つの物体に対応

### 5.5 なぜ2段階のFFTなのか

#### 時間スケールの分離
- **距離**: 高速な変化（ビート周波数は数kHz〜MHz）
- **速度**: 低速な変化（ドップラーは数Hz〜数百Hz）

2つの物理現象が異なる時間スケールで現れるため、**直交する2軸で分離**できます。

#### フーリエ変換の性質
- チャープ内の高速変動 → 距離に起因
- チャープ間の低速変動 → 速度に起因

2次元FFTにより、この2つを独立に抽出できます。
