## 実験記録

### Q1-Q3: ステアリングベクトルの位相普遍性

#### 実験日
2025-11-17

#### 仮説（当初）
- ステアリングベクトルは物体の方向に依存した「固有の周波数」を持つ複素振動
- 同じ周波数の受信信号に対して、位相を変えても内積は一定（位相普遍性）

#### 実験内容
1. **信号の定義**（誤った方法）
   ```python
   freq = 5
   t = np.arange(0, 1, 0.01)
   x1 = np.sin(2 * np.pi * freq * t + phase)
   x2 = np.sin(2 * np.pi * freq * t + np.pi / 2 + phase)
   x_complex = x1 + 1j * x2
   ```

2. **ステアリングベクトル**
   ```python
   steering_vector = np.exp(-1j * 2 * np.pi * freq * t)
   ```

3. **内積計算**（誤った方法）
   ```python
   inner_product = np.sum(x_complex * steering_vector)
   ```

4. **位相を変化**
   - `phase` を 0 から π まで変化
   - 各位相で内積を計算

#### 結果
- **内積がほぼゼロ**（e-14オーダー）
- 位相を変えても値はほぼゼロのまま
- 期待した「位相によらず一定」ではなく、「すべてゼロ」

#### 問題点の発見

AIとの対話により、以下の2つの問題を特定：

**問題1: 信号の定義が誤り**
- `sin(θ) + j·cos(θ)` と定義していた
- 正しい複素指数関数は `cos(θ) + j·sin(θ) = e^(jθ)`
- 実部と虚部が逆！
- 単純な90度位相差ではなく、そもそも別の形

**問題2: 内積計算で共役を取っていない**
- `np.sum(a * b)` を使用
- 正しくは `np.vdot(a, b)` または `np.sum(np.conj(a) * b)`
- 複素内積には共役転置が必須

#### 修正後の実験

```python
# 正しい複素指数関数
x_complex_correct = np.exp(1j * (2 * np.pi * freq * t + phase))

# 正しい共役内積
inner_product = np.vdot(steering_vector, x_complex_correct)
```

**結果**:
- 内積の絶対値が100（サンプル数と一致）
- 位相を変えても絶対値は一定
- **位相普遍性が確認できた！**

#### 学び

1. **複素指数関数の正しい形**
   - `e^(jθ) = cos(θ) + j·sin(θ)`
   - 実部が `cos`、虚部が `sin`
   - この順序を間違えると全く別の信号になる

2. **共役転置の必要性**
   - 複素内積: `<a, b> = Σ conj(a_i) × b_i`
   - 共役を取ることで「位相差」を計算できる
   - 共役を取らないと「位相和」になり意味が変わる

3. **位相普遍性の意味**
   - 全体位相回転 `e^(jφ) · a(θ)` は物理的に無意味
   - 重要なのは相対位相のみ
   - ステアリングベクトルマッチングでは絶対位相に依存しない

4. **データ長の影響**
   - アンテナ素子数が変わっても、正規化すれば問題ない
   - 内積の絶対値は素子数Mに比例
   - 正規化: `a / sqrt(M)` で素子数に依存しない

5. **深層学習との違い**
   - 深層学習: 実数ベクトル、位相が変われば内積が変化
   - レーダー: 複素ベクトル、全体位相によらず内積一定
   - この違いの根源は「共役転置」

#### 疑問点
- ✅ なぜ共役を取ると「位相差」になるのか？ → 数学的に理解済み
- ⬜ 空間周波数とは具体的に何か？ → 次の実験（Q4）で確認
