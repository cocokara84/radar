## レーダー固有の「暗黙知」リスト

深層学習者が見落としやすい、レーダー信号処理特有の前提知識：

### 1. 複素数の内積には必ず共役を使う
- **暗黙の前提**: `<a, b> = a^H · b`（共役転置）
- **深層学習との違い**: 実数ベクトルでは共役不要
- **理由**: 位相情報を正しく扱うため

### 2. ステアリングベクトルは正規化する
- **暗黙の前提**: `||a(θ)|| = 1`
- **理由**: アンテナ素子数に依存しない比較のため

### 3. 位相は「相対的」であり絶対値は無意味
- **暗黙の前提**: 全体に位相回転を加えても物理的に同じ
- **例**: `e^(jφ) · a(θ)` と `a(θ)` は同じ方向を指す

### 4. 空間領域と時間領域の類似性
- **暗黙の前提**: 時間のFFT ≈ 空間のビームフォーミング
- **混乱ポイント**: 変数名が `t` でも「時間」ではなく「アンテナインデックス」の場合がある

### 5. 周波数が同じでも「異なる信号」がある
- **深層学習者の誤解**: 同じ周波数 = 同じ信号
- **レーダーの真実**: 周波数が同じでも到来角（空間周波数）が異なれば別の信号

### 6. ノイズ部分空間と信号部分空間の直交性
- **MUSICの核心**: 信号ステアリングベクトルはノイズ部分空間に直交
- **深層学習との類似**: PCAの主成分分析に似ている

## よくある誤解と学習記録

### 2025-11-17: sin + j·cos ≠ e^(jθ) の誤解

#### 誤った理解
- `sin(θ) + j·cos(θ)` は `e^(jθ)` に90度の位相差をつけたもの

#### 正しい理解
- `e^(jθ) = cos(θ) + j·sin(θ)` であり、実部と虚部が逆
- `sin(θ) + j·cos(θ)` は複素指数関数として表現できない別の形
- 単純な位相回転では変換できない

#### 学んだこと
1. 複素指数関数は `cos + j·sin` の形でなければならない
2. 複素数の内積には共役転置が必要
3. ステアリングベクトルとの内積で共役を取らないと誤った結果になる

## AIへの指示

### 基本原則
1. **実装を見たら必ず意図確認**
   - コードの問題を指摘する前に「何を実現しようとしていますか？」と質問
   - 学習者の理解レベルを推定しない（必ず確認する）

2. **段階的な説明**
   - 最初は概念レベル（物理的意味、深層学習との対比）
   - 次に数式レベル（必要最小限）
   - 最後に実装レベル（コード例）

3. **暗黙知の明示化**
   - 「当たり前」と思われることも必ず説明
   - レーダー特有の前提は明示的に記載

4. **実験ファースト**
   - いきなり答えを教えない
   - 「こういう実験をしてみてください」と提案
   - 結果を見てから解説

### 禁止事項
- ❌ いきなり複雑な数式を提示する
- ❌ 「これは基本です」「常識です」と言う
- ❌ 実装コードを先に見せる（学習者に考えさせる）
- ❌ 複数の概念を一度に説明する

### 推奨事項
- ✅ 深層学習との対比で説明
- ✅ 視覚的な例（複素平面のプロット等）
- ✅ 小さな実験から始める
- ✅ 1つの概念を完全に理解してから次へ
