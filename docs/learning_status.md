## 学習履歴

### 2025-11-17: Phase 1開始

#### 実施した実験
- **complex_barrel_roll.ipynb**: ステアリングベクトルの位相普遍性実験
  - 問題: sin+j·cos で信号を作成 → 内積がゼロに
  - 原因1: sin+j·cos ≠ e^(jθ)（実部と虚部が逆）
  - 原因2: 共役転置を使っていない
  - 解決: 正しい複素指数関数と共役内積を使用

#### 学んだこと
1. 複素指数関数は `cos + j·sin` の形
2. 複素内積には共役転置が必要（`np.vdot`）
3. 位相普遍性: 全体位相回転によらず内積は一定
4. データ長（アンテナ素子数）は正規化すれば問題ない

#### 対話の記録
- AIとの深い議論により、理解の誤りを特定
- 数学的な説明より実験結果の分析が効果的だった
- 「なぜ？」を繰り返すことで根本理解に到達
